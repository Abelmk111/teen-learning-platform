# teen-learning-platform

A student learning website starter for teens with attendance, exam tracking, workbook tasks, learning materials, and login/signup.

## Features
- Student login and signup pages
- Dashboard overview cards
- Attendance tracking panel
- Exam schedule and grades
- Workbook assignments with progress tracking
- Learning materials section
- Responsive design for desktop and mobile

## Scripts
```bash
npm install
npm run dev
```

## Stack
- React

- React Router
